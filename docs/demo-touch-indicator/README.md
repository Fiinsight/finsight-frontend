# 발표용 터치 표시 검증 — 2026-11-03

프로필의 발표용 터치 표시 스위치로 켜고 끈다. 기본값은 꺼짐이며 기존 storage 래퍼에 설정 값만 저장한다. 좌표는 메모리에서 표시하고 저장·전송하지 않는다.

앱 루트와 RN Modal 11곳에 같은 오버레이를 적용했다. 버블링 터치 이벤트만 관찰하고 표시 레이어는 pointerEvents="none"이다. 이동은 Animated 값만 변경하므로 자식 앱을 다시 렌더하지 않는다. 44px 원, 멀티터치, 250ms 페이드, 짧은 탭 파문을 지원한다.

검증: npm run typecheck 및 npm test 197개 통과. 설정 복원·저장 실패·복원 경쟁, 비활성 표시 없음, 멀티터치 시작/이동/종료/취소, 좌표 오프셋, 파문, 웹 hover 제외, 모든 모달 적용 회귀 포함.

iOS 26.1 / iPhone 17 Pro / Expo Go: 설정 기본 꺼짐과 켜기, 앱 재로드 후 설정 유지, 하단 홈·프로필 전환, 홈 뉴스 카드 진입, 용어 모달 열기를 확인했다. 모달 화면 증거: [스크린샷](ios-term-modal.png).

미완료: 실제 손가락과 원 위치 일치, 홈 스크롤·차트 드래그·판단 텍스트 입력·모달 닫기 동작의 직접 검증. 자동화 좌표 클릭이 noWindowsAvailable 오류로 실패해 확인 완료로 기록하지 않았다. 시뮬레이터 멀티터치 직접 검증과 웹 실제 마우스 검증도 남았다. 따라서 PR은 draft로 생성한다.

한계: 시스템 키보드, 네이티브 시스템 팝업, 앱 밖 화면에는 표시되지 않는다. 모달·회전·상태바 환경에서 좌표 일치는 실기기 최종 확인이 필요하다. 새 의존성·백엔드·AI 변경 없음. main 머지 없음.
